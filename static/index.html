How memory is used

  • retain — every incident is decomposed into world facts (what was true of the system) and experience facts (what this team did: the fix, and the false lead that cost minutes). Each carries service, failure class, MTTR and incident ID as metadata.
  • recall — an incoming alert is fingerprinted and searched four ways at once: keyword, semantic, entity-graph and temporal. A second hop then pulls the root cause, fix and false lead for the incidents that ranked highest.
  • observations — repeated facts are consolidated into evidence-backed beliefs with a proof count, so the agent can say "3 of 3 times, this was the fix".
  • mental models — curated team playbooks that outrank everything else during reasoning.
  • grounding gate — if nothing in memory genuinely resembles the alert, the agent says so instead of pattern-matching. An on-call agent that confidently cites the wrong incident is worse than one with no memory at all.
